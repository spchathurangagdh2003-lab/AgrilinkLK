# AgriLinkLK 

AgriLinkLK is a web-based agriculture marketplace system.

## Features
- Farmer dashboard
- Buyer dashboard
- Admin dashboard
- Product and order management

## Technologies
- HTML, CSS, JavaScript
- Node.js
- Express.js
- MongoDB

## How to Run
1. npm install
2. Create a .env file
3. Add MongoDB connection string
4. npm start
